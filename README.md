# 거래량 레이더

실제 KOSPI/KOSDAQ 일봉으로 거래량 변화를 관찰하는 학습 도구입니다. 공개 주소: https://seaflo42-coder.github.io/volume-radar/

## 기본 관찰 목록 (2026-10-13 개정)

기존 발견 조건은 그대로입니다: **당일을 제외한 직전 20거래일 평균 거래량의 3배 이상, 전일 종가 대비 변화 ±3% 이내**. 새 기본 목록만 아래 기준을 모두 만족하는 신호로 좁힙니다.

- KRX KIND 상장법인 목록의 대표코드·시장·명칭을 대조한 일반주 후보
- **발견일 추정 거래대금 30억원 이상**
- **발견일 이전 20거래일 추정 거래대금 중앙값 10억원 이상**
- 기준일 거래량·종가 확인, 가격 기준 변경 및 점수 구성 미확인 제외

한 번의 거래량 급증만으로 평소 거래가 적은 종목이 들어오는 것을 줄이려는 운영 기준입니다. 기준은 이번 수집 전에 고정했으며 과거 수익률에 맞추어 최적화하지 않았습니다. 특정 주문 크기의 체결 가능성·수익·안전성을 보장하는 기준이 아닙니다. 추정 거래대금은 **종가 × 거래량**으로 실제 체결 합계·호가 깊이와 다릅니다. 중앙값은 일시적인 큰 거래일의 영향을 줄이지만 최근 유동성 변화와 거래비용을 완전히 반영하지 못합니다.

스팩은 KIND 코드 대조와 명칭으로 분리합니다. 우선주는 명칭 접미사와 기초회사 코드 앞 5자리·명칭을 대조한 **추정**입니다. 리츠·기타 명칭도 별도 분류합니다. 이름·시장 불일치, 기초회사 미확인, KIND 조회 실패는 유형 미확인으로 기본 목록에서 제외합니다. 일반주 후보도 공식 주식종류를 직접 확인한 결과는 아니며 현재 목록 대조 결과입니다. 분류 기준과 확인 수준을 상세 화면에서 제공합니다.

별도 보기의 스팩·우선주 추정·기타/미확인 및 기존 조건 전체는 새 거래규모 필터를 적용하지 않습니다. 비교용 기록으로 구분합니다. 적격 종목이 적으면 10개를 채우지 않습니다.

## 순위·가격 변화·통계

시세 기준 최근 5거래일(0~4일 전) 중 조건을 만족한 신호를 점수순으로 최대 10종목 표시합니다. 같은 종목은 해당 보기 범위에서 가장 높은 점수의 신호 하나를 사용합니다. 점수는 발견 당시의 규칙값으로 상승 확률·현재 매수 우선순위가 아닙니다.

- 거래량: min(35, max(0, 20 + 8 × (배수 − 3))). 4.875배부터 35점.
- 종가 변화: max(0, 25 − 7 × 절대 등락률(%)). 장중 변동성이나 안전성 점수가 아님.
- 종가 위치: 당일 저가~고가 중 종가 위치 × 15. 고가=저가면 중간값 적용.
- 합계 최대 75점. 미래 가격은 점수에 사용하지 않습니다.

가격 변화는 발견일 종가 대비 기준일 종가의 실제 변화로 표시합니다. 지지선·손절선·안전성 판단을 붙이지 않습니다. 거래량 증가 원인이나 기업 소개·뉴스 이유를 생성하지 않으며 DART·KRX 검색으로 직접 확인하도록 안내합니다.

**전체 신호 통계는 새 관찰 목록 TOP 10의 투자성과가 아닙니다.** 기존 조건의 전체 발견 기록을 보존하며 각 발견일 종가 대비 5/10/20거래일 후 종가를 비교합니다. 다음 거래일 실제 진입, 비용·세금·슬리피지·배당, 지수 대비 초과성과, 중복 보유 및 최대 손실 검증이 없습니다. 현재 상장 목록에 따른 생존자 편향과 동일 종목 반복 신호가 있습니다. 미래 미완료·가격 누락은 통계에서 제외합니다. 수정주가로 저장된 발견일 가격 기준이 달라지면 새 계산을 보류하고 기존 완료 결과는 보존하므로 완전한 기업행동 보정 수익률이 아닙니다.

## 출처·최신성

일봉과 시장 종목 목록은 네이버 금융 공개 응답입니다. 기업 목록은 https://kind.krx.co.kr/corpgeneral/corpList.do?method=download&searchType=13 에서 조회하며 요청 시각·SHA-256은 web/data/provenance.json에 기록합니다. 공개 응답의 구조·접근 정책 변경으로 실패할 수 있습니다. ETF·ETN·KONEX는 대상에서 제외합니다.

한국 시간 18시 이전은 직전 거래일, 이후는 당일 일봉을 사용합니다. 휴장일은 XKRX 캘린더로 처리합니다. **실시간 시세가 아니며 정기 자동 갱신은 OFF**입니다. 화면은 다음 거래일 18시부터 오래된 기록으로 표시하며, 30초 간격·탭 복귀·포커스 시 재판정합니다. 이 시각은 데이터 유효성 확인 기준이며 예약 실행 약속이 아닙니다.

수집 성공 비율이 98% 미만이면 이전 정상 시세를 보존합니다. 부분 누락은 표시합니다. KIND 조회 실패는 기본 목록을 비우고 유형 확인 실패를 표시합니다.

## 실행·검증·배포

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
node --test tests/frontend.cjs
.venv/bin/python -m pipeline.build
python3 -m http.server 8000 --directory web
```

파일을 직접 여는 대신 http://localhost:8000 을 사용합니다. GitHub Actions의 Market snapshot and Pages 워크플로를 수동 실행하면 저장된 검증 시세를 배포합니다. refresh_data=true는 전체 시세를 먼저 수집합니다. 이번 개정에서도 schedule은 주석 상태입니다. ChatGPT 브리핑 자동화와 무관합니다.
